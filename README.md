# MeyREN Gateway

این پروژه یک گیت‌وی سبک مبتنی بر پروتکل VLESS به همراه پنل تحت وب است که امکان اجرا روی پلتفرم‌های ابری مثل Railway را فراهم می‌کند. با فورک کردن ریپازیتوری و استقرار آن، پنلی برای مدیریت کاربران، صدور لینک‌های اتصال و پایش مصرف ترافیک در اختیار خواهید داشت.

### مراحل کلی استفاده

1. نصب نرم‌افزارهای کلاینت مانند v2rayNG (اندروید)، NekoBox (ویندوز و اندروید) یا Sing-box.
2. ورود به پنل، ساخت لینک اتصال یا کپی لینک اشتراک (Subscription).
3. افزودن لینک یا سابسکریپشن به برنامه و برقراری اتصال.

---

## راه‌اندازی روی Railway

### ۱. کپی کردن پروژه (Fork)

در بالای همین صفحه روی دکمه Fork کلیک کنید تا یک نسخه از پروژه روی حساب گیت‌هاب شما ساخته شود.

### ۲. اتصال به Railway

1. وارد سایت [Railway.app](https://railway.app) شوید و با حساب GitHub خود وارد شوید.
2. روی New Project کلیک کنید.
3. گزینه Deploy from GitHub repo را انتخاب کرده و مخزن MeyREN را برگزینید.

### ۳. استقرار سرویس و ساخت دامنه

1. روی Deploy کلیک کنید. راه‌اندازی اولیه بین ۱ تا ۲ دقیقه طول می‌کشد.
2. پس از پایان استقرار و سبز شدن وضعیت پروژه، وارد تب Settings شوید.
3. در بخش Networking روی Generate Domain کلیک کنید تا آدرس اختصاصی پنل ایجاد شود.

### ۴. ورود اولیه به پنل مدیریت

1. آدرس دریافت‌شده از Railway را باز کرده و در انتهای آن عبارت `/login` را قرار دهید (نمونه: `https://your-app.up.railway.app/login`).
2. رمز عبور پیش‌فرض برای ورود `admin` است.
3. نکته امنیتی: پس از اولین ورود، از تب Security رمز عبور مدیریت را تغییر دهید.

## راهنمای استفاده از پنل

### ساخت اینباند و تنظیم محدودیت‌ها

1. در صفحه پنل روی Add کلیک کنید.
2. نام کاربر، سقف حجم، محدودیت سرعت (Mbps)، سقف تعداد دستگاه‌های متصل همزمان (IP Limit)، مدت اعتبار (روز) و دسته مورد نظر را مشخص کنید. وارد کردن عدد 0 در هر بخش به معنی نامحدود بودن آن است.
3. روی Create کلیک کنید تا کانفیگ به همراه QR Code و لینک اشتراک ساخته شود.

### افزودن به نرم‌افزار کلاینت

- لینک مستقیم: لینک کپی‌شده یا بارکد QR را مستقیماً وارد برنامه کنید. این پنل علاوه بر VLESS WebSocket از ترنسپورت VLESS XHTTP نیز پشتیبانی می‌کند.
- لینک اشتراک (Subscription): با کپی کردن آدرس سابسکریپشن در برنامه کلاینت، تمام کانفیگ‌های فعال به صورت خودکار دریافت و به‌روزرسانی می‌شوند.
- پورتال اختصاصی کاربر (Client Portal): هر کاربر دارای یک صفحه اختصاصی تحت وب است که میزان مصرف، روزهای باقی‌مانده، بارکد و دکمه‌های اتصال مستقیم به برنامه‌های v2rayNG، Sing-box، Clash و Shadowrocket را نمایش می‌دهد.

### مدیریت کاربران و ترافیک

- جستجو: پیدا کردن سریع کانفیگ‌ها بر اساس نام یا UUID کاربر.
- فیلتر وضعیت: تفکیک کاربران فعال از کاربران غیرفعال یا پایان‌یافته.
- محدودیت سرعت و دستگاه: کنترل سقف پهنای باند و تعداد آی‌پی همزمان بدون اختلال در عملکرد سایر کاربران.
- شارژ سریع و صفر کردن ترافیک: امکان افزودن ۱ گیگابایت حجم یا ریست کردن میزان مصرف هر کاربر.
- تغییر وضعیت (Toggle): قطع یا وصل موقت دسترسی بدون نیاز به حذف کانفیگ.
- پایش مصرف: مشاهده ترافیک مصرفی همراه با نمودار درصد مصرف هر کاربر.
- حذف: پاک کردن کانفیگ‌های قدیمی و بی‌استفاده.

## بخش‌های پنل مدیریت

| بخش | عملکرد |
| --- | --- |
| Dashboard | نمایش آمار کلی سرویس، ترافیک کل، تعداد کاربران، مدت زمان کارکرد سرور (Uptime)، نمودار سرعت مصرف لحظه‌ای، وضعیت پردازنده و رم. |
| Inbounds | مدیریت کانفیگ‌ها، ساخت لینک VLESS WS و XHTTP، تنظیم محدودیت سرعت و دستگاه، لینک اشتراک و پورتال کاربران. |
| Groups & Mixer | دسته‌بندی کانفیگ‌ها و ایجاد لینک‌های اشتراک ترکیبی (Mixer) برای دسترسی به چند سرور در یک لینک. |
| Traffic | گزارش تجمیعی ترافیک مصرفی و درخواست‌های ثبت‌شده. |
| Announcements | ثبت و مدیریت اطلاعیه‌ها و پیام‌های سیستمی برای نمایش در پنل و صفحه اختصاصی کاربران. |
| Admins & RBAC | مدیریت مدیران و سطوح دسترسی (مدیریت کاربران، مشاهده آمار، دسترسی به لاگ‌ها). |
| Audit Logs | ثبت گزارش‌های امنیتی و تاریخچه فعالیت‌های انجام‌شده توسط مدیران به همراه آی‌پی و زمان. |
| Network Tools | ابزار پینگ تاخیر شبکه و تست اتصال آی‌پی‌های تمیز کلودفلر (Clean IPs). |
| Security | تغییر رمز عبور ورود به پنل مدیریت. |

## متغیرهای محیطی و تنظیمات اختیاری

در صورت اجرای پروژه روی سرور شخصی یا نیاز به تنظیمات اختصاصی در بخش متغیرهای محیطی (Environment Variables):

- `ADMIN_PASSWORD`: رمز عبور مدیر پیش‌فرض (پیش‌فرض: `admin`).
- `SECRET_KEY`: کلید امنیتی برای رمزگذاری نشست‌ها و توکن‌ها (در صورت خالی بودن، به طور خودکار تولید و ذخیره می‌شود).
- `DEFAULT_DOMAIN`: دامنه پیش‌فرض مورد استفاده در تولید کانفیگ‌ها و لینک‌های اشتراک.
- `PORT`: درگاه ارتباطی سرور (پیش‌فرض: `8000`).
- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام از BotFather برای فعال‌سازی ربات همراه مدیریت پنل (اختیاری).
- `TELEGRAM_ADMIN_IDS`: شناسه‌های عددی ادمین‌های تلگرام با دسترسی به ربات (اختیاری).
- `DB_PATH`: مسیر فایل پایگاه داده SQLite (پیش‌فرض: `meyren.db`).
